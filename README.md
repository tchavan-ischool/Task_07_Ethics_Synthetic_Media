# Task 07 — Ethics of Synthetic Representation

## Overview

This project examines the ethical and governance implications of synthetic media using the practical experience developed in Task 6.

Task 6 involved creating and evaluating:

1. AI-generated audio using ElevenLabs
2. AI-generated avatar video using Vidnoz AI

The experiment examined realism, pacing, emotional expression, synchronization, disclosure, and synthetic-media detection.

The most significant result occurred during the detection experiment.

An audio recording known to be completely AI-generated using ElevenLabs received an **AI score of only 16%** and was classified as **"Likely Human"** by an automated AI voice detector.

This false-negative result provides the central case study for the ethical and governance analysis in this repository.

---

# Research Question

The central question is:

> How should organizations govern synthetic media when realistic AI-generated content may be difficult for humans or automated detection systems to reliably identify?

- prohibited uses
- consent

# Connection to Task 6

Task 6 demonstrated that realistic synthetic media can be produced using accessible AI tools.

Two generation approaches were evaluated:

## ElevenLabs

A synthetic narration was generated using the Siren voice.

Version 1 was highly realistic and received a 95% human rating for voice naturalness.

However, subtle characteristics involving breathing and transitions remained noticeable.

The final audio was later classified as "Likely Human" by an automated detector.

## Vidnoz

A synthetic avatar named Annie was used with the Annie (Lifelike) voice.

The strongest characteristics were lip synchronization and body/head movement.

Facial expression and vocal emotion were less realistic.

A second iteration using stronger pauses was perceived as less realistic than the first.

---

# Key Ethical Finding

The Task 6 experiment demonstrated that three concepts must be distinguished:

**Realism**

How convincing an artifact appears.

**Detection**

Whether a person or automated system believes an artifact is synthetic.

**Provenance**

Documented information about how the artifact was actually created.

These concepts are related but are not equivalent.

The ElevenLabs artifact was realistic, was classified as likely human by an automated detector, but had clear provenance establishing that it was completely synthetic.

# Core Principle

The central principle developed through this project is:

> **Realistic presentation is not evidence of authenticity, and automated detection is not proof of origin.**

Responsible synthetic-media use therefore requires multiple safeguards including disclosure, provenance, consent, factual verification, and human review.

---

# Ethical Scope

No new synthetic media representing a real identifiable person was created for this project.

The ethical analysis is based on synthetic voices and stock/synthetic avatars created during Task 6.

No real person's face or voice was cloned.

---

# Conclusion

Synthetic media can provide legitimate value for research communication, accessibility, education, and experimentation.

However, the Task 6 experiment demonstrated that realistic synthetic media may not always be reliably identified by automated detection.

Organizations therefore need governance systems that do not depend on detection alone.

This project proposes a layered approach based on:

**verification + consent + disclosure + provenance + human review + incident response + refusal authority**
